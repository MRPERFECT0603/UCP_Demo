Protocol Overview

What is UCP?

GET /.well-known/ucp

{
  "capabilities": {
    "catalog": "Search & filter products",
    "checkout": "Create & manage cart",
    "payment": "Init & verify payment",
    "orders": "Track order status"
  }
}
🔍
Catalog
Search by keyword, brand, color, price range. Returns ranked product list with images and metadata.
🛒
Checkout
Create session, update quantity, apply coupons. Merchant owns cart state; agent holds the session ID.
💳
Payment
Init returns a payment token + available methods. Verify confirms the transaction and returns an order.
📦
Orders
Track delivery status, get ETA, retrieve order history by order ID.

Each capability is optional and self-describing — the agent reads the manifest first and only calls capabilities the merchant has declared. Merchants can adopt UCP incrementally, one capability at a time.

UCP Core

Merchant Discovery

GET /.well-known/ucp

// Response from Flipkart
{
  "merchant": "Flipkart",
  "version": "1.0",
  "capabilities": {
    "catalog": { "endpoint": "/ucp/catalog/search" },
    "checkout": { "endpoint": "/ucp/checkout" },
    "payment": {
      "initEndpoint": "/ucp/checkout/:id/payment/init",
      "verifyEndpoint": "/ucp/checkout/:id/payment/verify"
    }
  }
}
✅ No Hardcoding
Agent discovers endpoints dynamically at runtime
🔌 Plug & Play
Add a new merchant by registering one URL
📋 Capability-Driven
Agent only calls what the merchant advertises
🔄 Auto-Refresh
Re-fetches manifest before payment to get latest endpoints

Checkout Lifecycle

Checkout Session State Machine

PENDING
CART UPDATED
PAYMENT INITIATED
PAYMENT VERIFIED
✅ CONFIRMED
POST /ucp/checkout
Creates session, returns sessionId
Agent stores sessionId for all future calls
PUT /ucp/checkout/:id
Update qty, apply coupons
Can be called multiple times — merchant recalculates total each time
POST /payment/init
Returns payment token + methods
Token is time-limited (600s). Agent re-fetches UCP manifest to get fresh endpoint.
POST /payment/verify
Validates token, confirms order
Merchant records the order. Agent receives orderId and delivery ETA.
